Kurikulum Praktik

Silabus Pembelajaran Workshop

Kurikulum didesain secara sistematis agar peserta dapat langsung mengimplementasikannya di Rumah Sakit masing-masing.

01
Modul 1: Arsitektur PACS Modern & Setup Orthanc PACS

Mempelajari dasar teknologi PACS berbasis open-source yang efisien dan stabil:

  • Instalasi PACS Server Orthanc (Lintas Sistem Operasi).
  • Konfigurasi penyimpanan internal dan plugin penting (Serve Folders, Explorer 2, Worklists).
  • Hosting JawaraLite Viewer secara native menggunakan plugin Serve Folders (Solusi Tanpa CORS).
  • Menambahkan aksi pintas peluncuran studi langsung pada antarmuka Orthanc Explorer 2.
02
Modul 2: Otomatisasi Worklist Modalitas dengan Mirth Connect

Membangun jembatan data medis terotomatisasi dari SIMRS hingga ke mesin pemeriksaan (modalitas):

  • Setup Channel MLLP TCP Listener di Mirth Connect untuk menerima HL7 ORM.
  • Membangun HTTP Sender untuk mem-forward data ke server Node.js Receiver.
  • Parsing HL7 segment PID (Data Pasien) dan OBR (Data Pemeriksaan).
  • Mengompilasi text dump menjadi file DICOM Worklist (.wl) biner menggunakan DCMTK `dump2dcm`.
  • Pengujian query DICOM C-FIND Modality Worklist (MWL) dari modalitas.
03
Modul 3: Integrasi SIMRS & Web Viewer JawaraLite

Menghubungkan rekam medis elektronik SIMRS dengan gambar radiologi secara langsung:

  • Membuka penampil gambar DICOM JawaraLite menggunakan URL Deep Link.
  • Alur fallback resolusi data: Query otomatis ke PACS via patientID dan accessionNumber.
  • Penanganan degradasi pencarian otomatis apabila nomor aksesi spesifik tidak ditemukan.
  • Render citra medis secara cepat pada peramban web radiolog.
04
Modul 4: Kepatuhan Regulasi Kemenkes RI & Integrasi SatuSehat

Memenuhi kewajiban integrasi Rekam Medis Elektronik Nasional sesuai regulasi Kemenkes RI:

  • Memahami struktur resource FHIR SatuSehat (`ImagingStudy` & `DiagnosticReport`).
  • Mapping data pemeriksaan radiologi ke payload JSON standar Kemenkes.
  • Autentikasi API SatuSehat (OAuth 2.0 Client Credentials).
  • Enkripsi dan protokol pengiriman data pasien yang aman.
